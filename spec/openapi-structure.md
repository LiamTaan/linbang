# 邻里互助用户中心与资金域 OpenAPI 结构

## App API

- `/app-api/member/role-context/*`
  - 当前角色上下文与角色切换
  - `currentRoleCode` 是 App 当前操作身份的唯一判定口径
  - `enabledRoleCodes` 仅表示已开通/可切换角色，不代表当前页可直接执行该角色动作
- `/app-api/order/*`
  - `createOrder` / `previewOrder` 为普通用户侧发单接口，必须当前角色为 `USER`
  - 普通用户侧范围判断按“当前业务地址”生效：首页首次进入默认自动定位生成业务地址草稿，用户也可切换到任意已保存地址或重新填写跨区地址
  - `accept/page`、`accept/detail`、`accept/create` 以及服务商履约相关动作属于服务商接口，必须当前角色为 `MERCHANT`
  - 服务商需求大厅按服务区域过滤；普通用户浏览类需求/服务内容按当前业务地址过滤；区域合作商不进入该共用业务页
  - 订单分页支持业务分类：待接、服务中、已完成、售后、待评价、待付款、已退款
  - 订单详情返回统一时间线：订单、单元、支付、退款、投诉、申诉、操作日志
  - 订单修改
  - 订单取消
  - 单元核销码查看
  - 单元核销
  - 核销日志查询
- `/app-api/wallet/*`
  - 钱包首页 / 我的账户总览
  - 钱包流水分页/详情
  - 推广收益摘要增强字段
  - 银行卡分页/详情/新增/删除/设默认
  - 银行卡仅作为提现收款账户管理，不对外宣称已完成第三方鉴权绑卡
  - 提现申请/分页/详情
  - 提现打款结果以银盛商户付款查询/通知结果为准
- `/app-api/member/role-apply/*`
  - 身份申请分页 / 详情
  - 推广员、区域合作商身份申请；平台管理员保留给管理端或内部流程，不在 App 身份页展示
- `/app-api/member/address/*`
  - 地址列表、详情、新增、修改、删除、坐标解析、附近地点查询
  - 首页自动定位结果仅作为当前业务地址草稿，不应直接硬保存为默认地址
  - 保存默认地址前，前端必须允许用户补全联系人、联系电话、详细门牌；用户首条有效地址自动成为默认地址
- `/app-api/partner/*`
  - 区域合作商工作台、辖区详情、辖区入驻初审、辖区纠纷协调、辖区价格建议、辖区推广数据、会议通知/上级指令
  - 所有接口均为 `PARTNER` 当前角色专属接口
  - 所有分页与详情字段必须说明辖区范围、状态语义、是否允许当前合作商继续操作
  - 统计字段必须说明真实业务口径：
    - `todayNewUserCount`：按用户有效默认地址归属辖区的今日新增注册用户统计；有效默认地址优先取显式默认地址，没有显式默认时取首个有效地址，不得按订单用户反推
    - `pendingEntryAuditCount`：按辖区内服务商入驻申请 `PENDING` 状态统计
    - `pendingComplaintCount`：按辖区内投诉 + 申诉待处理记录统计
    - `priceSuggestion` / `priceReport`：语义统一为合作商辖区价格建议单，需标明创建、撤回、审核结果口径
    - `promoteStat`：按辖区内推广关系、推广转化、佣金单和推广成交额等真实推广业务对象统计，不得仅按订单列表倒推
- `/app-api/merchant/entry/*`
  - 服务商入驻提交、当前入驻申请、入驻进度查询
  - 服务商是接单 / 抢单主体，入驻后开通服务商身份
- `/app-api/member/qualification/*`
  - 资质详情
  - 到期提醒与认证进度查询
- `/app-api/reminder/*`
  - 生日提醒、自定义事件提醒 CRUD
  - 提醒列表
  - 提醒历史
  - 证件到期提醒统一聚合查询
- `/app-api/promote/*`
  - 推广中心
  - 两级团队统计与收益摘要
- `/app-api/reward-order/*`
  - 我发布的悬赏列表
  - 我参与的悬赏列表
  - 悬赏详情
  - 悬赏创建
  - 参与悬赏
  - 参与记录分页
  - 本轮最小闭环复用晒单悬赏申请与参与记录表
- `/app-api/pay/order/*`
  - 创建支付单：微信、支付宝、H5、钱包等前端支付方式统一提交到 `aggregate` 聚合支付通道
  - 查询支付单
  - 支付回调通知：仅按第三方回调与查询结果中的 `trade_status=TRADE_SUCCESS` 判定支付成功
- `/app-api/pay/refund/*`
  - 创建退款申请
  - 查询退款分页
  - 查询退款详情
  - 退款回调通知：以银盛退款查询与通知中的最终退款状态判定
- `/app-api/order/*`
  - 订单详情内返回托管凭证、退款记录、结算解锁信息
- `/app-api/platform-config/*`
  - App 设置
  - 税务提醒
  - 个体执照代办入口
- `/app-api/help/faq/*`
  - 常见问题启用列表
  - 常见问题详情
  - 支持按分类与关键字查询
- `/app-api/help/feedback/*`
  - 提交意见反馈
  - 我的反馈记录分页
  - 我的反馈详情

## Admin API

- `/admin-api/order/info/*`
  - 订单分页、详情、编辑、删除
  - 详情展示单元核销信息与统一时间线
- `/admin-api/order/unit/*`
  - 单元分页、详情、解锁
  - 详情展示核销字段与单元时间线
- `/admin-api/member/role-apply/*`
  - 身份申请分页、详情、审核
  - 差异化展示代理、推广员、平台管理员申请字段
- `/admin-api/merchant/entry/*`
  - 服务商入驻分页、详情、审核
- `/admin-api/wallet/account/*`
- `/admin-api/wallet/flow/*`
- `/admin-api/wallet/withdraw/*`
- `/admin-api/wallet/bank-card/*`
- `/admin-api/wallet/divide-rule/*`
- `/admin-api/wallet/commission-order/*`
- `/admin-api/wallet/escrow-proof/*`
- `/admin-api/pay/refund-context/*`
- `/admin-api/help/faq/*`
  - 常见问题分页、详情、新增、修改、删除、导出
  - 默认初始化资金与提现、订单相关、认证与入驻、抢单与匹配、推广与佣金
- `/admin-api/help/feedback/*`
  - 用户意见反馈分页、详情、导出

## 文档要求

- 所有金额字段统一单位为元，若为支付模块原始字段需注明“分”。
- 所有状态字段必须描述枚举值语义。
- 所有关联 ID 需注明指向对象。
- 所有角色相关接口必须明确当前角色要求、已开通角色的含义，以及角色不匹配时的失败语义。
- 所有核销字段必须明确：核销作用域、核销状态、核销码是否可见、核销时间、核销人含义。
- 所有身份申请字段必须明确角色适用范围，不能只给字段名不说明适用角色。
- 所有提醒字段必须明确：提醒类型、重复规则、下一次提醒时间、最近一次触发时间、是否系统生成、是否允许编辑。
- “我的悬赏”接口必须在文档中明确：本轮交付复用晒单悬赏申请主表，并新增参与记录表补齐“我参与的悬赏”和参与记录查询。
- 钱包、提现、退款、分账、托管凭证必须提供列表和详情字段说明。
- 帮助中心常见问题必须明确分类编码、分类名称、问题标题、答案正文、排序、启停状态；App 只展示启用状态。
- 帮助反馈必须明确反馈分类、反馈内容、联系电话、处理状态、处理备注和用户摘要。
